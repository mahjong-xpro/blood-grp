# GRP 训练常见问题

## Q: GRP 需要先训练，还是自动训练的？

**A: 需要先训练或创建 GRP 模型**

### 为什么需要 GRP？

1. **训练主模型时必需**：数据加载器在训练开始时会立即加载 GRP 模型
2. **用于计算奖励**：GRP 用于计算训练数据的奖励（reward），这是强化学习训练的核心
3. **如果 GRP 文件不存在，训练会报错**

### 解决方案

#### 方案 1：创建随机 GRP 模型（快速开始）

```bash
cd mortal
python ../scripts/create-initial-grp.py
```

这会创建一个随机初始化的 GRP 模型，可以立即开始训练主模型。

**优点**：
- 快速，立即可用
- 不需要数据

**缺点**：
- 预测不准确，可能影响训练效果

#### 方案 2：先用少量数据训练 GRP（推荐）

```bash
# 1. 进行少量自对局生成数据（如 200 局）
# 2. 训练 GRP
cd mortal
python train_grp.py
# 或
./scripts/blood-train-grp.sh
```

**优点**：
- GRP 预测更准确
- 训练效果更好

**缺点**：
- 需要先有数据

#### 方案 3：迭代改进（最佳实践）

```
1. 创建随机 GRP 模型
2. 开始主模型训练（使用随机 GRP）
3. 进行自对局生成数据
4. 用新数据重新训练 GRP
5. 继续主模型训练（使用改进的 GRP）
6. 定期重复步骤 3-5
```

## Q: 没有 GRP 模型可以训练吗？

**A: 不可以**。训练主模型时，`dataloader.py` 会立即尝试加载 GRP 模型文件。如果文件不存在，会报错：

```
FileNotFoundError: [Errno 2] No such file or directory: '/data/mortal/grp.pth'
```

## Q: 可以用随机 GRP 模型开始吗？

**A: 可以**。虽然随机 GRP 预测不准确，但可以让训练开始。随着训练进行，可以定期用新数据重新训练 GRP。

## Q: GRP 需要多少数据？

**A**: 
- **最少**：几百局对局数据就可以开始训练
- **推荐**：几千到几万局数据
- **随着训练进行**：使用更多数据重新训练 GRP

## Q: 需要定期重新训练 GRP 吗？

**A: 建议定期重新训练**

- **初期**：每生成一批新数据后重新训练 GRP
- **后期**：可以降低频率（如每 5-10 轮重新训练一次）

原因：
- 随着主模型改进，对局模式会变化
- 使用新的对局数据训练 GRP 可以提高预测准确性
- 更准确的 GRP 可以改善主模型的训练效果

## Q: GRP 训练需要多长时间？

**A**: 
- **少量数据**（几百局）：几分钟到十几分钟
- **中等数据**（几千局）：半小时到几小时
- **大量数据**（几万局）：数小时

## Q: GRP 训练和主模型训练可以并行吗？

**A: 不建议并行**

- GRP 训练需要读取对局数据文件
- 主模型训练也在使用这些数据
- 并行可能导致文件访问冲突

**建议流程**：
1. 主模型训练 → 生成新数据
2. 停止主模型训练
3. 用新数据训练 GRP
4. 继续主模型训练（使用新的 GRP）

## 快速命令参考

```bash
# 创建随机 GRP 模型
cd mortal && python ../scripts/create-initial-grp.py

# 训练 GRP
cd mortal && python train_grp.py
# 或
./scripts/blood-train-grp.sh

# 检查 GRP 模型是否存在
ls -lh /data/mortal/grp.pth
```
