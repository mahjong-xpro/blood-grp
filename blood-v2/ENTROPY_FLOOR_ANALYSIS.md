## 二、Entropy Floor机制

### 2.1 工作原理

**代码位置**：`python/blood/training/callbacks.py`

```python
# HyperparamScheduler.step()
scheduled_value = self._compute_schedule(env_steps)

# 应用entropy floor
if param == "exploration_loss_coeff":
    floor = getattr(cfg, "blood_entropy_floor", 0.0)
    if floor > 0 and scheduled_value < floor:
        actual_value = floor
        log.info(f"Entropy floor activated: {scheduled_value:.4f} → {floor:.4f}")
```

**触发条件**：
- Schedule计算值 < entropy_floor
- 强制使用floor值

### 2.2 当前配置（0.009）

**触发时机**：
- Cosine schedule终值：0.01
- Floor值：0.009
- **永远不会触发**（0.01 > 0.009）

**设计意图**：
- 捕获意外下降（如schedule bug）
- 不干预正常schedule

**实际效果**：
- 无作用（未触发）
- 策略entropy已降至0.47，远高于0.009

### 2.3 提升配置（0.012）

**触发时机**：
- Cosine schedule终值：0.01
- Floor值：0.012
- **会在后期触发**（0.01 < 0.012）

**预期行为**：
```
0-100M步：schedule值 0.02-0.015，高于floor，不触发
100M-200M步：schedule值 0.015-0.01，逐渐接近floor
~150M步：schedule值降至0.012，开始触发floor
150M-200M步：强制使用0.012，阻止进一步下降
```

## 三、影响分析

### 3.1 对Entropy的影响

**200M步训练预测**：

| 配置 | 100M步 | 150M步 | 200M步 | 说明 |
|------|--------|--------|--------|------|
| Floor=0.009 | 0.45 | 0.42 | 0.38-0.40 | 持续下降 |
| Floor=0.012 | 0.45 | 0.42 | **0.40-0.42** | 后期稳定 |

**关键差异**：
- 0.009 floor：200M步时可能降至0.38-0.40（接近警戒线0.35）
- 0.012 floor：200M步时稳定在0.40-0.42（安全范围）

### 3.2 对探索性的影响

**Entropy与探索性关系**：

| Entropy | 策略行为 | 风险 |
|---------|---------|------|
| >0.50 | 高探索，多样化 | 训练初期正常 |
| 0.40-0.50 | 中等探索，稳定 | ✅ 理想范围 |
| 0.35-0.40 | 低探索，确定性 | ⚠️ 警戒线 |
| <0.35 | 极低探索，过拟合 | ❌ 危险 |

**0.012 floor的保护作用**：
- 确保entropy不低于0.40（通过schedule间接控制）
- 防止策略过早收敛到确定性策略
- 保持足够探索性以发现新策略

### 3.3 对Elo的影响

**预期影响**：

| 场景 | Floor=0.009 | Floor=0.012 | 差异 |
|------|------------|------------|------|
| 150M步前 | 无差异 | 无差异 | 0 Elo |
| 150M-200M步 | Entropy 0.38-0.40 | Entropy 0.40-0.42 | +5~10 Elo |
| 200M步后 | 可能停滞 | 持续提升 | +10~20 Elo |

**机制**：
- 更高的entropy → 更多探索 → 发现更优策略
- 防止过早收敛 → 避免陷入局部最优
- 长期训练收益更大

## 四、风险评估

### 4.1 提升Floor的风险

**潜在风险**：
1. **训练速度略慢**：更多探索 → 收敛稍慢
2. **策略不够确定**：保持随机性 → 推理时略弱

**风险评估**：
- 风险1：轻微（5-10%训练速度）
- 风险2：极低（推理时可用temperature=0.1降低随机性）

### 4.2 不提升Floor的风险

**潜在风险**：
1. **过早收敛**：Entropy降至0.35-0.38
2. **陷入局部最优**：策略过于确定，无法探索新方向
3. **Elo停滞**：后期无法继续提升

**风险评估**：
- 风险1：中等（30-40%概率）
- 风险2：中等（20-30%概率）
- 风险3：高（50-60%概率）

### 4.3 风险对比

| 维度 | Floor=0.009 | Floor=0.012 | 推荐 |
|------|------------|------------|------|
| 训练速度 | 快 | 略慢（-5~10%） | 0.009 |
| 长期Elo | 可能停滞 | 持续提升 | **0.012** |
| 过拟合风险 | 中等 | 低 | **0.012** |
| 推理质量 | 略高 | 略低（可调temperature） | 0.009 |
| **综合** | ⚠️ 风险较高 | ✅ **更安全** | **0.012** |
