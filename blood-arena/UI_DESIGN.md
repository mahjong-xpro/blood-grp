# 血战到底 界面设计说明

## 业务逻辑

1. **对局阶段**
   - **未开始**：只显示「开始对局」，无牌面。
   - **定缺**：每人选一门（万/筒/条）；仅「我」需要操作，显示三个按钮。
   - **行牌**：轮流 摸牌→出牌 或 碰/杠/和；我方可 出牌（点牌）或 过/碰/杠/荣和/自摸。
   - **结束**：三人和牌即结束，弹层显示结果与「再来一局」。

2. **数据唯一来源**
   - 四人身份固定：我=下(0)，对手=右(1)/上(2)/左(3)。不重复罗列。
   - 分数、定缺：只属于每个座位 → 只在座位条显示一次。
   - 当前回合：只在一处表达 → 高亮当前座位。
   - 我的操作：只在一处 → 我座位下方的一条操作栏（有按钮显示按钮，无则靠点牌出牌）。

## 信息架构（一物一处）

| 信息         | 唯一位置                     |
|--------------|------------------------------|
| 标题 + 入口  | 顶栏左（标题）、右（开始/再来一局） |
| 状态文案     | 顶栏中，一行                 |
| 姓名/分数/定缺 | 各座位底部信息条，不重复     |
| 当前回合     | 高亮当前座位边框             |
| 我的操作     | 仅「我」下方的操作栏         |

## 布局原则

- **顶栏**：标题 | 状态 | 主按钮。不显示四家分数。
- **牌桌**：四边对称。每边结构统一：河牌 → 副露 → 手牌 → 信息条（姓名、分数、定缺徽章）。
- **中央**：极简，仅「剩 N 张」或小圆点表示轮到我，无大标题/箭头。
- **操作栏**：仅在我（下家）下方，有 validActions 时显示按钮组，无时隐藏（出牌=点牌）。

## 视觉原则

- 深色底、牌桌略亮，减少干扰。
- 当前回合：座位边框或背景轻微高亮，不闪烁。
- 操作按钮：小药丸样式，定缺 万/筒/条 用红/蓝/绿，和牌用主色。
