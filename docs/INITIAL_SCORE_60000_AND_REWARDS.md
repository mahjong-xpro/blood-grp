# 基础分 60000 对奖励系统的影响

> 结论：**不会对奖励系统产生负面影响**。局得失分（kyoku_rewards）、排名目标（player_ranks）、定缺辅助（ding_que）均与基础分无关；唯一变化是观测里分数通道的归一化尺度，属输入分布变化，不影响奖励或价值目标。

---

## 一、奖励与目标如何计算

| 信号 | 计算方式 | 是否依赖绝对分数 |
|------|----------|------------------|
| **kyoku_rewards** | `calc_delta_points()`：分数序列的一阶差分 → 再除以 10000 | **否**：只依赖**得分变化**（deltas） |
| **player_ranks** | `Rankings::new(final_scores)`：按最终分排序得 0/1/2/3 | **否**：只依赖**相对顺序** |
| **ding_que_quality / ding_que_bonus** | 手牌与定缺花色的匹配度，与分数无关 | **否** |

---

## 二、为何 60000 不影响奖励

1. **局得失分（kyoku_rewards）**
   - `scores_history` = 每局**开始时**的 4 家分数，`final_scores` = 终局分数。
   - `delta_points = seq[1:] - seq[:-1]`，即**相邻时刻分数之差**。
   - 对局中的点数流动来自和牌/流局/杠的 **deltas**（如 +1000、-2000），与起始分 25000 还是 60000 **无关**。
   - 因此同样的对局，25000 基与 60000 基的 **delta_points 完全一致** → **kyoku_rewards 一致**，Q 目标 `gamma^steps_to_done * kyoku_rewards + ding_que_bonus` 不变。

2. **排名（player_ranks）**
   - 只依赖 `final_scores` 的**大小关系**，不依赖总分或起始分。
   - 60000 基下谁分高谁排前，与 25000 基逻辑相同 → **next_rank 目标不变**。

3. **定缺**
   - 定缺质量/奖励只看手牌与所选缺门，与分数无关 → **不变**。

---

## 三、唯一相关变化：观测中的分数编码

- 分数在观测里被归一化：`v = score / TOTAL_SCORE`（25000 基时除以 100000，60000 基时除以 240000）。
- “起步分”在两种设定下都是 0.25（25000/100000 = 60000/240000）。
- **差异**：同样的**点数差**（例如 +10000）在归一化后的变化幅度不同：
  - 25000 基：10000/100000 = 0.10；
  - 60000 基：10000/240000 ≈ 0.042。
- 即：**同样的得失分，在 60000 基下分数通道的数值变化更小**，相当于该维对“点数领先/落后”的敏感度降低。
- **影响**：仅影响**输入分布**；**奖励与价值目标（Q target）未变**。若价值头主要从 rank、deltas 等学，影响通常很小；若非常依赖“当前分数”这一维，理论上可能略弱化该维信号，可观察一段时间内的 value / dqn loss 是否异常。

---

## 四、总结

| 项目 | 60000 基是否改变 | 说明 |
|------|------------------|------|
| 局得失分 kyoku_rewards | 否 | 只依赖 deltas，与起始分无关 |
| 排名目标 player_ranks | 否 | 只依赖最终分排序 |
| 定缺相关 ding_que_* | 否 | 与分数无关 |
| Q 目标 / 价值目标 | 否 | 由 kyoku_rewards + ding_que_bonus 决定 |
| 观测中分数通道的尺度 | 是 | 同一得失分对应更小的归一化变化，属输入分布变化 |

**结论**：改成 60000 分**不会对奖励系统产生负面影响**；奖励与排名、定缺逻辑均与基础分无关。唯一变化是观测里分数维的敏感度，属可接受的输入分布变化，必要时可通过 TensorBoard 监控 value/dqn 相关指标。
