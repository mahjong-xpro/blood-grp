# 左右玩家河牌间距过大 — 深度分析

## 1. 问题描述

- **现象**：左右玩家（上家、下家）的河牌间距太大，与 ME 玩家河牌间距不一致
- **期望**：各方位河牌间距应统一

## 2. 根因分析

### 2.1 河牌布局结构

| 方位 | 布局方向 | 河牌 flex-direction | 牌尺寸 (W×H) |
|------|---------|---------------------|--------------|
| ME (zone-bottom) | 横向 | row | 26×36 px |
| 对家 (zone-top) | 横向 | row-reverse | 26×36 px |
| 上家 (zone-left) | 纵向 | column-reverse | 26×36 px |
| 下家 (zone-right) | 纵向 | column-reverse | 26×36 px |

### 2.2 间距计算

Flexbox 的 `gap: 2px` 作用于主轴（main axis）。

**ME / 对家（横向）**：
- 主轴 = 水平方向
- 每张牌在主轴上的尺寸 = **width = 26px**
- 牌间距 = **2px**
- **相邻牌中心距 = 26 + 2 = 28px**

**左右玩家（纵向）**：
- 主轴 = 垂直方向
- 每张牌在主轴上的尺寸 = **height = 36px**
- 牌间距 = **2px**
- **相邻牌中心距 = 36 + 2 = 38px**

### 2.3 根因结论

| 方位 | 主轴尺寸 | 间距 | 中心距 |
|------|---------|------|--------|
| ME / 对家 | 26px | 2px | **28px** |
| 上家 / 下家 | 36px | 2px | **38px** |

左右玩家河牌在主轴上的尺寸是 36px，ME 是 26px，导致中心距相差 10px（约 36%），视觉上明显更松。

## 3. 修复方案

将左右玩家河牌在主轴上的尺寸从 36px 改为 26px，使中心距与 ME 一致（28px）。

**实现**：为 `.zone-left .river .tile` 和 `.zone-right .river .tile` 交换宽高：

```css
.zone-left .river .tile,
.zone-right .river .tile {
    width: var(--tile-h-sm);   /* 36px — 跨轴，河牌“厚度” */
    height: var(--tile-w-sm);  /* 26px — 主轴，与 ME 一致 */
}
```

- 主轴（column）方向：每张牌 26px + 2px gap → 中心距 28px ✓
- 旋转（rotate 90deg / -90deg）不变，牌面仍朝向中心
- 跨轴 36px 保证旋转后的牌不溢出
