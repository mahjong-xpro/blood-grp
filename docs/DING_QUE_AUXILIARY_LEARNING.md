# 定缺辅助学习方案

## 问题：定缺为什么难学

1. **单次决策、回报滞后**  
   定缺在每局开始时只做一次（三选一：万/筒/条），而局结果要很多步之后才出现，信用分配很难。

2. **信号稀疏**  
   主奖励是局末得分/排名，定缺选择混在大量后续决策里，梯度对「选哪门缺」的区分度弱。

3. **探索有限**  
   只有 3 个动作，若没有额外学习信号，策略容易在定缺上收敛慢或偏向次优。

## 现有基础设施

- **`libblood/src/dataset/grp.rs`**  
  - `GameScore.ding_que_quality`: 每局每人一个标量，表示该局定缺选择质量。  
  - 计算方式：对三种缺门分别算「去掉该花色后的向听 + 刻子惩罚 - 对对潜力」得到 cost，选 cost 最低为 +1（最佳）、最高为 -1（最差）、中间为 0。  
  - 已在 replay 时写入，但 **dataloader 中此前被注释掉**，未参与训练。

- **动作空间**（`libblood/src/consts.rs`）  
  - 定缺对应 action 索引：31 = Man，32 = Pin，33 = Sou。  
  - 定缺步可通过「该步选择的 action ∈ {31,32,33}」识别。

## 方案概览

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **A. 定缺步奖励塑形** | 仅在「定缺步」给即时奖励：`bonus = ding_que_quality * scale`，与局末得分一起作为 Q 目标 | 实现简单，信号直接作用在定缺步，不改变网络结构 | 启发式可能偶有偏差，需控制 scale 避免盖过真实得分 |
| **B. 定缺步 BC 辅助损失** | 仅在定缺步加监督损失：用启发式「最佳花色」作软标签或 one-hot，对策略头做 CE/KL | 不改变主奖励，只拉高选「好缺」的概率 | 需要传 per-step 的 is_ding_que 与 target suit；启发式错时会产生错误监督 |
| **C. 定缺专用头** | 增加一个小头：输入同 obs，输出 3 维「最佳缺门」logits，用 ding_que_quality 构造软标签训练；推理时可用该头加权或约束策略 | 与主策略解耦，可单独调权重 | 实现与调参更复杂，推理要改 action 采样逻辑 |
| **D. 仅重开定缺奖励** | 恢复早期「整局加 ding_que_quality」的写法（对整局所有步加同一 bonus） | 改动最小 | 错误：整局每步都加，会严重干扰非定缺步的 Q 学习，不推荐 |

**推荐优先实现 A**：在 dataloader 中只对「定缺步」加上 `ding_que_bonus`，在 Q 目标里使用「局末回报 + 定缺步即时 bonus」，并加配置开关与 `ding_que_scale`，便于消融和调参。

## 推荐实现：方案 A（定缺步奖励塑形）

### 1. 数据侧（dataloader）

- 从 `game_score.take_ding_que_quality()` 取 `ding_que_quality`（形状：每局 × 4 人）。
- 对每个 step `i`：  
  - 若 `actions[i] in {31, 32, 33}`，则视为该玩家的定缺步，取  
    `ding_que_bonus[i] = ding_que_quality[at_kyoku[i], player_id] * ding_que_scale`  
  - 否则 `ding_que_bonus[i] = 0`。
- 将 `ding_que_bonus` 作为 per-step 数组一并放入 buffer（与 obs/actions/masks/steps_to_done/kyoku_rewards/player_ranks 等一起）。

### 2. 训练侧（train）

- 读取 `ding_que_bonus`，与 `kyoku_rewards`、`steps_to_done` 一起传入 `train_batch`。
- Q 目标改为：  
  `q_target_mc = gamma ** steps_to_done * kyoku_rewards + ding_que_bonus`  
  即：局末回报按步数折扣 + 定缺步的即时 bonus（仅在定缺步非零）。

### 3. 配置

- `[aux]` 或 `[env]` 下增加：  
  - `ding_que_aux_scale`：定缺 bonus 系数（如 0.01～0.05，不宜过大）。  
  - `ding_que_aux_enabled`：是否启用定缺辅助（默认 true，便于关闭做消融）。

### 4. 注意点

- 仅定缺步有 bonus，非定缺步为 0，避免污染其他步的 Q。  
- `ding_que_quality` 为 [-1, 1]，scale 建议小（如 0.02），使辅助信号存在但不主导。  
- 若后续发现启发式偏差大，可考虑方案 B/C 或改进 `grp.rs` 中的 `evaluate_ding_que_quality`（例如引入简单 SP 或听牌形状）。

## 方案 B（已实现）：定缺步 CE 监督

- **Rust**（`libblood/src/dataset/grp.rs`）：新增 `ding_que_best_suit: Vec<[u8; 4]>`，每局每人存启发式最佳花色索引 0=Man/1=Pin/2=Sou；`best_ding_que_suit_index(tehai)` 与 `take_ding_que_best_suit()`。
- **数据**：每步增加 `ding_que_best_suit` 标签；仅定缺步为 0/1/2，非定缺步为 -1。
- **训练**：仅在 `ding_que_best_suit >= 0` 的样本上对 Q 头在动作 31/32/33 上做交叉熵损失，权重 `ding_que_ce_weight`（config 中默认 0.1）。与方案 A 叠加使用。

## 启发式改进（已实现）：刻子/顺子/对子质量 + 进张种类

- **刻子（triplet）**：去掉该门时，每失去一个 刻子（同种牌 ≥3 张）加 penalty 0.8，优先不定缺「有成刻」的门。
- **顺子（sequence）**：去掉该门时，每失去一个完整 顺子（如 123、234…，贪心计数）加 penalty 0.7；`count_sequences_in_suit` 对该门 9 种牌贪心抽取 顺子 个数。
- **对子（pair）**：去掉该门时，每失去一个 对子（同种牌恰好 2 张；刻子不重复计）加 penalty 0.35；对子可作将牌或进刻，损失小于刻子/顺子。
- **进张种类**（`count_improvement_kinds`）：对去掉该门后的手牌，统计有多少种牌加一张能减向听；种类越多 cost 减越多（improvement_bonus，上限 2.0）。
- 仍不依赖牌山/`tiles_seen`，仅用向听接口，适合 replay。

## 整体回顾：是否影响奖励系统、应不应该做

### 会不会影响整体奖励系统？

- **主奖励不变**：局内计分仍是「局末得分变化」→ `kyoku_rewards`，零和、对局结果不变；主信号仍是得分/排名。
- **方案 A（奖励塑形）**：只在**定缺步**把 Q 目标从「折扣局末回报」改成「折扣局末回报 + 定缺 bonus」。  
  - 影响范围：**仅定缺步**的 Q 目标被塑形；非定缺步完全不变。  
  - 本质：在定缺步多了一个与启发式质量挂钩的**即时奖励**，相当于给「选好缺」一点额外正回报，拉高该步的 Q，不改变其他步的回报定义。
- **方案 B（CE 监督）**：不改 Q 目标、不改奖励；只在定缺步对策略头加一个**辅助损失**，把策略往「启发式最佳花色」拉。  
  - 影响：**不改变奖励系统**，只改变定缺步上的梯度方向。
- **结论**：主奖励（得分）仍是唯一「对局结果」信号；定缺辅助是在定缺步上**加了一层启发式引导**（A 改该步 Q 目标，B 改该步梯度），**不改变非定缺步的奖励与目标**，也不改变对局的零和性。

### 应不应该做？

| 角度 | 说明 |
|------|------|
| **收益** | 定缺单次决策、回报滞后，主奖励对「选哪门缺」区分度弱；加辅助后定缺步有直接信号，有利于更快学到合理定缺，且启发式（刻子/顺子/对子/进张）与「少丢成组牌」一致，和主目标大致对齐。 |
| **风险** | 启发式会偶发错误（如个别局面下「高 cost 门」反而该定缺）；若权重过大可能压制主奖励、偏向启发式。当前 scale/weight 较小（0.02、0.1），主奖励仍主导。 |
| **可控性** | 可通过 `ding_que_aux_enabled=false`、`ding_que_ce_weight=0` 做消融，对比有无定缺辅助的胜率/得分。 |
| **建议** | **建议做**：在保持主奖励不变、仅定缺步加引导的前提下，用较小权重做定缺辅助，有利于样本效率和定缺质量；上线前后可用消融验证是否带来收益，若有负向再关掉。 |

## 优化空间

| 方向 | 内容 | 优先级 |
|------|------|--------|
| **启发式** | 若有 replay 时的 `tiles_seen`，用 SP 的 `get_required_tiles` 进张数加权替代「种类数」，cost 更贴近真实期望 | 中（依赖数据） |
| **启发式** | 搭子（如 12、23 等两牌形状）可加小惩罚：失去搭子比散牌略亏，比顺子轻；需在门内数「可成顺的 2 张块」 | 低 |
| **权重** | 对 `ding_que_aux_scale`（0.01/0.02/0.05）、`ding_que_ce_weight`（0.05/0.1/0.2）做小规模网格搜索，看胜率/定缺对齐 | 中 |
| **训练** | 定缺辅助权重随训练衰减：前期偏启发式、后期偏主奖励，减少长期偏差 | 低 |
| **监控** | 在 tensorboard 打点「定缺与启发式一致率」：定缺步中 `action == ding_que_best_suit` 的比例，便于观察是否在学 | 高 |
| **方案 C** | 定缺专用头（输入 obs，输出 3 维最佳缺门），用软标签训练，推理时与主策略加权/约束；与主 Q 解耦，可单独调 | 低（实现成本高） |
| **单测** | 当前 grp 单测需链接 Python 才能跑；可加 pytest 调 Rust 扩展测 cost，或在 CI 用 maturin 跑 `cargo test` | 低 |

**建议优先**：加「定缺与启发式一致率」监控，便于判断定缺是否在学、辅助是否有效；再视需要做权重搜索或进张数改进。
