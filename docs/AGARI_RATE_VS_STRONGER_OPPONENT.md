# 为什么换更强的对手后，和牌率反而更高？

和牌率在代码里是 **agari_rate = agari / round**（你在多少局里和了牌）。对手变强、你却和得更多，主要有以下几类原因。

---

## 1. 强对手更敢冲，放炮更多（最常见）

- **强对手**：牌好时会更积极进攻（推牌、听牌早），听牌后打危险牌的概率更高，**放炮（点你荣和）** 次数会上去。
- **弱对手**：可能偏保守、不推牌，很少点炮，你多半只能靠**自摸**和牌。
- 结果：对手变强 → 你**荣和**变多 → 总和的局数变多 → **和牌率上升**。  
  所以和牌率升不一定代表你“变强了”，而是**对手风格更进攻、给你更多荣和机会**。

---

## 2. 弱对手的“乱打”在挡你

- 弱/随机对手会**碰、杠你需要的牌**，或打乱牌序，让你的进张变差。
- 强对手出牌更“合理”、局面更可预测，你的模型在这种分布下可能**更容易成型**，和牌率反而上去。

---

## 3. 局数/节奏差异（统计口径）

- 强对手可能更快结束一局（先自摸），**总局数 (round)** 可能和之前不一样。
- 若 test 的局数变少，而你在这些局里和到的次数相对多，**agari/round** 就会升高。  
  建议看 TensorBoard 里 **test_play/behavior** 的 **agari** 与 **houjuu**（流局/未和）比例，以及 **round** 总数是否和换对手前接近。

---

## 4. 方差（样本量）

- test_play 若只有几千局，和牌率会有波动，**短期“升高”可能只是噪声**。  
  多跑几个 test_every，看和牌率是否稳定在一个更高水平，再判断是否真实效应。

---

## 建议怎么确认

1. **看 TensorBoard**  
   - **test_play/behavior**：agari / houjuu / fuuro 比例。  
   - 若有**荣和 vs 自摸**的拆分（或从日志里算），看和牌率上升主要来自荣和还是自摸。

2. **和“放炮率”一起看**  
   - 若 **houjuu_rate**（你点炮给别人的比例）没明显变差，而和牌率升了，多半是**别人点你更多**（强对手更敢打），符合上面的 1。

3. **多看几步**  
   - 再跑 1～2 个 test_every，看和牌率是否持续 > 换对手前，再下结论。

**总结**：换强对手后和牌率更高，很多时候是因为**强对手更进攻、放炮更多**，你荣和多了；不一定代表你比之前更强，要看是否主要是荣和增加、以及放炮率是否稳定。
